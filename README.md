Resolução do desafio de lógica de programação em Java (Sprint 01) feito no **IntelliJ IDEA**. 

Módulos do Projeto (Pacote org.example)

1. **ComandaRestaurante.java**: Sistema de pedidos do restaurante Sabor & Arte. Calcula o total acumulado com base nas escolhas do cardápio fixo.
2. **CensoSocioeconomico.java**: Menu interativo para cadastro de habitantes e cálculo automático de indicadores (médias, maior/menor idade e filtros de gênero/salário).

Como Compilar e Executar (Terminal)

Abra o terminal na pasta raiz do projeto e siga os passos: 

1. Compilar os arquivos

bash

javac src/main/java/org/example/*.java -d out


2. Executar o Módulo 01 (Comanda)

bash

java -cp out org.example.ComandaRestaurante

Use o código com cuidado.

3. Executar o Módulo 02 (Censo)

bash

java -cp out org.example.CensoSocioeconomico

Use o código com cuidado.
